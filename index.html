Générer le rapport hebdomadaire

Synthèse locale des éléments publiés au cours des 7 derniers jours, avec chiffres, titres et liens de sources.

Cliquez sur « Générer le résumé ».

Structure du rapport

  • Synthèse générale de la semaine.
  • Répartition par catégorie et niveau de sévérité.
  • Principales alertes, fuites et vulnérabilités.
  • Liens vers les sources originales.
  • Limites : résumé basé sur les métadonnées des flux, pas sur une analyse complète de chaque article.
Ce rapport est une aide à la veille, pas une qualification officielle. Confirmez les incidents et l'impact auprès de sources primaires.

Les flux de sources.json sont lus par GitHub Actions. Pour ajouter durablement un flux, modifiez ce fichier dans GitHub ou importez-y votre export.

À propos des données

Les éléments ajoutés ici et les flux ajoutés dans l'interface restent dans le stockage local de votre navigateur. Ils ne sont pas partagés avec les autres visiteurs du site GitHub Pages.

Pour partager une entrée manuelle avec les utilisateurs du site, ajoutez-la au fichier de données du dépôt ou mettez en place une source de données centralisée.
